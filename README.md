# YouGile_API_UI
_Тестирование системы управления проектами и командной работой YouGile._
Проверяется корректность работы трёх ключевых функций веб-сайта:
- авторизация и работа с проектами, работа с задачами и пользователями.

## Стек
- pytest
- selenium
- requests
- allure-pytest
- flake8

## Структура
- ./tests - директория с тест-кейсами, разделенными по типам:
  - api - API-тесты. Проверяют работу бэкенда через HTTP-запросы.
  - ui - UI-тесты (ТК-100 – ТК-106). Проверяют пользовательский интерфейс с помощью Selenium.
- ./pages - директория, содержащая классы страниц.
   Каждый класс инкапсулирует локаторы элементов и методы для взаимодействия с конкретной страницей.
- ./api - класс для работы с API-тестами.
- ./utils/config.py — читает файл .env и хранит настройки.
- .env -  файл конфигурации, содержащий переменные окружения
          (URL-адреса, учетные данные, токены API, настройки браузера).
          Читается модулем config.py.
- conftest.py - центральный файл конфигурации Pytest.
  Содержит фикстуры (setup/teardown), которые автоматически применяются к тестам.
- pytest.ini - конфигурационный файл Pytest.
- README.md - файл с описанием проекта, инструкциями по установке и запуску.
- requirements.txt - список всех внешних библиотек (зависимостей), необходимых для работы проекта.
- .gitignore — список файлов и папок, которые Git должен игнорировать
  (например, .venv, __pycache__, allure-results).

## Шаги
1. Склонировать проект "https://github.com/AlenaSub76/Diploma/pulls"
2. Установить зависимости командой 'pip install -r requirements.txt'
3. В файле .env **обязательно** заполнить учётные данные пользователя,
   необходимые для авторизации в REST API:
    - **YOUGILE_TOKEN=ВАШ_ТОКЕН**
    - **YOUGILE_USER_ID=ВАШ_USER_ID**
4. Запустить тесты:
  - 'pytest' - запускает прогон всех тестов в проекте с автоматичсеким 
               формированием отчета Allure.
  - 'pytest -m api' - запускает прогон только API-тестов,
  - 'pytest -m ui' - запускает прогон только UI-тестов.
5. Посмотреть временный отчет в Allure: 'allure serve allure-results'.
6. Ссылка на страницу проекта в Yonote: https://subbotina-aa-qa.yonote.ru/share/328f00d5-d55d-497b-962a-ee832eca6653
